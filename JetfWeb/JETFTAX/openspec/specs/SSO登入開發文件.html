進口快遞管理系統 SSO 登入 API

SSO 登入串接規格與簽章產生工具

GET http://192.168.1.9/JETF/login/sso

API 資訊

URL http://192.168.1.9/JETF/login/sso
驗證方式 HMAC-SHA256
Secret Key 7f3c6e9a-8b41-4e2d-9a6f-2c8d1e5b0a73
Timestamp 有效時間 30 秒

Request

參數 必填 型別 說明
userId 是 string 進口快遞管理系統使用者代碼，帳號必須存在且為啟用狀態
timestamp 是 long 呼叫當下的 UTC Unix Timestamp，單位為秒
sign 是 string HMAC-SHA256 簽章，64 字元小寫十六進位

Request URL 格式

http://192.168.1.9/JETF/login/sso?userId={userId}&timestamp={timestamp}&sign={sign}

請將使用者的瀏覽器導向此 URL，讓瀏覽器取得進口快遞管理系統登入 Session。

Sign 產生方式

1. 組合簽章原文

userId={userId}&timestamp={timestamp}

2. 使用 HMAC-SHA256 計算

sign = HMAC-SHA256(
    key: UTF8(Secret Key),
    data: UTF8(簽章原文)
)

3. 轉成小寫十六進位字串

Secret Key：7f3c6e9a-8b41-4e2d-9a6f-2c8d1e5b0a73
簽章原文：userId=Jetf001&timestamp=1780202356
sign：941b19479afa204467ebecaa397438335f5951d0fa99b6e9d8100c7121624583

固定 timestamp 僅供核對簽章結果；實際呼叫必須使用當下的 UTC Unix Timestamp 秒數。

Response

登入成功 302 Found

HTTP/1.1 302 Found
Location: /JETF/LoginSuccess/Index
Set-Cookie: ASP.NET_SessionId=...

成功後建立進口快遞管理系統 Session 並導向登入成功頁，不回傳 JSON。

登入失敗

{
  "code": "004",
  "message": "Sign 驗證失敗"
}
HTTP Status Code Message
400 Bad Request001缺少必要參數
400 Bad Request002Timestamp 格式錯誤
401 Unauthorized003Timestamp 已過期
401 Unauthorized004Sign 驗證失敗
403 Forbidden005使用者不存在或不可登入
